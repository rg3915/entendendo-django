# Entendendo o Django

Código dos vídeos da série **"Entendendo o Django"** do canal [Regis do Python](https://www.youtube.com/@RegisdoPython).
Todos usam o mesmo projeto de exemplo, a **Noite do Código** (chamada de palestras de um meetup), com Django 6.1 e Python 3.14.

| Pasta | Vídeo |
|---|---|
| [formularios](formularios/) | Entendendo os formulários do Django |
| [class-based-views](class-based-views/) | Entendendo as Class-Based Views do Django |
| [permissoes](permissoes/) | Quem pode fazer o quê? Permissões no Django |
| [django-ninja](django-ninja/) | Entendendo o Django Ninja |
| [django-rest-framework](django-rest-framework/) | Entendendo o Django REST Framework em 2026 |
| [drf-vs-ninja](drf-vs-ninja/) | DRF ou Django Ninja em 2026? |

Cada pasta é um projeto independente: entre nela e siga o README.

Requisitos: [uv](https://docs.astral.sh/uv/) e Python 3.14.

Projetos de estudo: `SECRET_KEY` e senhas do seed são de demonstração.
