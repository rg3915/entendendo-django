# Entendendo o Django Ninja

Código do vídeo "Entendendo o Django Ninja" do canal [Regis do Python](https://www.youtube.com/@RegisdoPython).

Projeto de estudo: a `SECRET_KEY` e as senhas do seed são de demonstração. Não use em produção.

```bash
uv sync
uv run python manage.py migrate
uv run python manage.py seed
uv run python manage.py runserver
```

Testes: `uv run python manage.py test`
